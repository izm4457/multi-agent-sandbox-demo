## 目的
TODO一覧を条件で絞り込めるようにする。

## 仕様
`src/filter.ts` に次を実装する。

```ts
export interface TodoFilter {
  status?: TodoStatus;          // 指定時はその状態のみ
  tags?: string[];              // 指定したタグを「すべて」含むもの（大文字小文字は無視）
  text?: string;                // title に部分一致（大文字小文字は無視、前後空白は無視）
  dueBefore?: string;           // YYYY-MM-DD。この日付「以前（当日含む）」に期限があるもの
}
export function filterTodos(todos: Todo[], filter: TodoFilter): Todo[];
```

- 条件は AND。未指定の条件は無視。空の `tags: []` や空文字 `text` は「条件なし」と同じ
- `dueBefore` 指定時、期限なし（`due` が undefined）のTODOは除外
- 入力配列を変更しない。並び順は入力の順を保つ
