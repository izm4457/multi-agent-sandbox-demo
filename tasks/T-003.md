## 目的
TODO一覧をターミナル表示用のテキストに整形する。

## 仕様
`src/format.ts` に次を実装する。

```ts
export function formatTodo(todo: Todo, today: string): string;   // today は YYYY-MM-DD
export function formatTodoList(todos: Todo[], today: string): string;
```

1行の形式：`[ ] #3 Buy milk  #home #errand  (due: 2026-10-14, in 2 days)`

- 状態：open は `[ ]`、done は `[x]`
- タグは `#tag` をスペース区切り。タグなしならタグ部分ごと省略
- 期限の相対表記：当日 `today`、翌日 `tomorrow`、前日 `yesterday`、それ以外は `in N days` / `N days overdue`
- done のTODOは相対表記を出さず `(due: YYYY-MM-DD)` のみ
- 期限なしなら期限部分ごと省略
- `formatTodoList`：1件ごとに改行で連結。0件なら `No todos.` を返す
- 日付計算はタイムゾーンに依存しないこと（UTCの日付として計算する）
