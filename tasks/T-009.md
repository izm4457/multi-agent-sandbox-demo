## 目的
T-008 で `shellcheck -S warning` を verify に組み込む前に、既存の警告をなくしておく。
（codex-fix.sh の警告は T-007 で直す）

## 仕様
`shellcheck -S warning` が出す次の警告を、**動作を変えずに** 直す。

| ファイル | 警告 | 直し方 |
| --- | --- | --- |
| scripts/codex-review.sh 31〜33 行目 | SC2155 `export X="$(...)"` | `X="$(...)"` と `export X` に分ける |
| scripts/opencode-worker.sh 16〜17 行目 | SC2155 | 同上 |
| scripts/commit-task.sh 30 行目 | SC2164 `cd "$WT"` | `cd "$WT" \|\| die "worktree に移動できません：${WT}"` |
| scripts/merge-task.sh 18 行目 | SC2164 `cd "$ROOT"` | `cd "$ROOT" \|\| die "リポジトリ直下に移動できません：${ROOT}"` |

- info レベルの指摘（SC1091、SC2086）は直さない。特に commit-task.sh の `$allowed`（SC2086）は意図的な単語分割なので引用符で囲まない
- 行番号はずれていてもよい。該当箇所を内容で探す

## 入力と不正入力
該当なし（各スクリプトの引数・終了コード・出力は変えない）

## レビュー観点チェックリスト
- 境界値：該当なし
- 日付：該当なし
- 引数：該当なし
- 取り違え：分割した変数名を取り違えていないか（`export` した名前とテンプレートの `{{...}}` が一致しているか）
- 並行実行：該当なし
- bash 3.2（macOS 標準）で動くこと。全角文字の直後に `$VAR` を置かず `${VAR}` を使う

## 受け入れ条件
- [ ] `shellcheck -S warning` が、上記4ファイルすべてで終了コード 0
- [ ] `bash -n` が上記4ファイルすべてで通る
- [ ] `npm run verify` が通る
