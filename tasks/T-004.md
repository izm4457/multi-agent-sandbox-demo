## 目的
T-001〜T-003 の部品をつなぎ、コマンドラインから使えるようにする。

## 仕様
`src/cli.ts` に、テストしやすい形で次を実装する。

```ts
export interface CliIO { stdout: (s: string) => void; stderr: (s: string) => void; today: string; }
export async function runCli(argv: string[], dataPath: string, io: CliIO): Promise<number>; // 終了コードを返す
```

サブコマンド：
- `add <title> [--tag t]... [--due YYYY-MM-DD]`
- `list [--status open|done] [--tag t]... [--text s] [--due-before YYYY-MM-DD]`
- `done <id>` / `rm <id>`

- 引数解析は `node:util` の `parseArgs` を使う（依存追加しない）
- 不正な引数・存在しないIDは stderr にメッセージを出して終了コード 1
- 各サブコマンドの正常系・異常系をテスト（一時ディレクトリの dataPath を使う）
