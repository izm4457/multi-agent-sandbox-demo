## 目的
TODO一覧をJSONファイルに保存・読み込みできるようにする。

## 仕様
`src/storage.ts` に次を実装する（`node:fs/promises` を使う）。

```ts
export async function loadTodos(path: string): Promise<TodoList>;
export async function saveTodos(path: string, list: TodoList): Promise<void>;
export class StorageError extends Error {}
```

- ファイル形式：`{ "version": 1, "todos": Todo[] }`
- `loadTodos`：ファイルが存在しなければ空の `TodoList` を返す
- 壊れたJSON・`version` 不一致・`todos` が配列でない場合は `StorageError` を投げる（メッセージにパスを含める）
- 復元には `TodoList.fromArray` を使う
- `saveTodos`：一時ファイルに書いてから `rename` する（書き込み途中で壊れないように）。親ディレクトリがなければ作る

## 受け入れ条件
- [ ] 保存→読み込みで内容と次のIDが保たれるテスト
- [ ] 存在しないファイル・壊れたJSON・version不一致のテスト
- [ ] テストは OS の一時ディレクトリ（`os.tmpdir()` + `mkdtemp`）を使い、後片付けする
- [ ] `npm run verify` が通る

## 範囲外
- ファイルロック、複数プロセスからの同時書き込み
